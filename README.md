# 戦略17分野 官民投資ロードマップ Treemap（2026年7月版）

日本成長戦略本部が2026年7月21日に決定した「戦略17分野における『主要な製品・技術等』の官民投資ロードマップ」全62項目を、**官民投資額**と**経済波及効果**の2軸で切り替えられるTreemapとして可視化したものです。

**公開ページ → https://<ユーザー名>.github.io/<リポジトリ名>/**

## できること

- タイル面積を「官民投資額」⇄「経済波及効果」で切り替え
- 配色を「分野別」⇄「投資効率（波及効果÷投資額の倍率）」で切り替え
- 重複計上されている2項目（グリーン鉄、バイオ医薬品・再生医療等製品等）の除外トグル
- 各タイルにホバー／タップで投資額・波及効果・投資倍率・想定年限を表示

## データについて

`data/roadmap2026_62items.csv` に抽出済みデータを置いています（64行 = 62項目 + 再掲2件）。

| 列 | 内容 |
|---|---|
| 分野 | 戦略17分野の分野名 |
| 主要な製品・技術等 | 項目名 |
| 官民投資額_兆円 | 想定投資額。空欄は金額未確定（艦艇、LNG運搬船） |
| 経済波及効果_兆円 | 産業連関分析による一次＋二次波及の合算 |
| 想定年限 | 2040年度までが基本。項目により2030／2033／2034／2035年度まで |
| 再掲フラグ | 1 = 2分野に重複掲載されている項目の2件目 |

### 数値を扱う際の注意

- **経済波及効果は項目間で重複があり、単純合算できません。** 図中の合計はあくまで参考値です。
- **投資額の単純合計はPDF記載の「370兆円超」を上回ります。** これは政府側で重複排除・精査を行った結果との差で、個別項目の値はPDF記載どおりです。
- 「グリーン鉄」（マテリアル②／GX③）と「バイオ医薬品・再生医療等製品等」（合成生物学・バイオ②／創薬・先端医療③）は2分野に重複掲載されています。既定では前者側に1回のみ計上。
- ロードマップはPDCAサイクルの中で改定される旨がPDFに明記されています。本データは**2026年7月21日決定版**に基づきます。
